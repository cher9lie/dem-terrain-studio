# 开发路线

## 阶段 0：视觉样机

- 使用真实省级灰度高度图和色带图；
- 自动生成位移平面、贴图、太阳光、白色地面和相机；
- 输出 Eevee 预览、Cycles 成图和可编辑 `.blend`；
- 确认高度方向、色带对齐、阴影方向和构图。

## 阶段 1：稳定的渲染核心

- 参数校验和 Blender 自动探测；
- 高度图位深、颜色空间和尺寸一致性检查；
- 预览/标准/高质量预设；
- 任务取消、日志和缓存；
- GPU 探测与 CPU 回退。

## 阶段 2：桌面界面

- PySide6 单窗口界面；
- 高度图和色带图选择；
- 太阳、相机、高程强度和输出参数；
- 低分辨率预览；
- 项目配置保存和加载。

## 阶段 3：自动制图

- 从 DEM 自动归一化并导出 16 位高度图；
- 自动生成蓝—绿—黄—灰高程色带；
- 支持绝对海拔和分位数两种色带策略；
- 可选省界裁切和 Alpha 掩膜；
- 保留 GIS 软件预处理输入方式。

## 阶段 4：独立实体地形

- 根据 Alpha 或省界生成异形轮廓；
- 添加垂直侧壁和封闭底面；
- 支持底座厚度、圆角和悬浮阴影；
- 导出 OBJ/GLB/STL。

## 验收重点

- 灰度 0 对应最低处、255/65535 对应最高处；
- 高度图和色带图无旋转、镜像或半像元错位；
- 外围白色区域不产生异常凸起；
- 地形比例、相机方向和太阳方向可重复；
- 256、512、1024 细分档位不会意外耗尽内存；
- 没有 Blender 时给出明确安装和路径提示。
