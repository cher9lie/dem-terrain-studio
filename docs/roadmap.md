# 开发路线

## 阶段 0：视觉样机

- [x] 使用合成 8/16 位、透明、平坦和非正方形高程图完成 Blender 实测；
- [x] 自动生成位移平面、自然色带、太阳光、白色地面和相机；
- [x] 输出 Eevee PNG 和可编辑 `.blend`；
- [x] 确认高程归一化、色带对齐、太阳方向、透明背景和构图；
- [ ] 使用用户提供的真实省级 DEM 完成最终样例验收。

## 阶段 1：稳定的渲染核心

- [x] 参数校验和 Blender 自动探测；
- [x] 高度图位深、颜色空间和尺寸一致性检查；
- [x] NoData 边缘检测、宽高比保持和纹理降采样；
- [x] Blender 异常退出、旧输出误判和输入覆盖保护；
- [x] Windows Python 2/3 启动冲突处理；
- [x] wheel 构建和 Blender 脚本随包发布；
- 预览/标准/高质量预设；
- 任务取消、日志和缓存；
- GPU 探测与 CPU 回退。

## 阶段 2：桌面界面

- PySide6 单窗口界面；
- 高度图和色带图选择；
- 太阳、相机、高程强度和输出参数；
- 低分辨率预览；
- 项目配置保存和加载。

## 阶段 3：自动制图

- [x] 在 Blender 内自动归一化 DEM；
- [x] 自动生成蓝—绿—黄—灰高程色带；
- 支持绝对海拔和分位数两种色带策略；
- [x] 支持 Alpha/一致边框 NoData 掩膜；
- 可选矢量省界裁切；
- 保留 GIS 软件预处理输入方式。

## 阶段 4：独立实体地形

- 根据 Alpha 或省界生成异形轮廓；
- 添加垂直侧壁和封闭底面；
- 支持底座厚度、圆角和悬浮阴影；
- 导出 OBJ/GLB/STL。

## 验收重点

- 灰度 0 对应最低处、255/65535 对应最高处；
- 高度图和色带图无旋转、镜像或半像元错位；
- 外围白色区域不产生异常凸起；
- 地形比例、相机方向和太阳方向可重复；
- 256、512、1024 细分档位不会意外耗尽内存；
- 没有 Blender 时给出明确安装和路径提示。
