# 合并说明草稿

建议标题：Render watertight terrain blocks from real geographic DEM masks

原始地理 TIFF 的多波段可能被混成错误高程，省界外与内部 NoData 也只通过贴图显示，无法形成独立封闭地形。当前分支增加显式高程波段、米制重投影和相对真实尺度的预处理工具；网格只覆盖有效区，自动构建外侧墙、孔洞内壁和平底，多块分离地形分别封闭，对角点相接时拆分顶点避免非流形。轮廓外的颜色延展避免纹理插值白边，源掩膜保持不变。

同时打包 BLEND 纹理，修正 Windows/安装后 CLI 的中文日志编码，匹配 SPDX 元数据所需的构建依赖版本，补充可选 geo 依赖。基础 wheel 仍没有新增强制依赖。地理预处理默认保留掩膜，矩形向内收边须显式指定 --trim-border。

## 验证

- 18 项单元测试通过，含全部非空 3×3 掩膜、64 组随机掩膜的边/顶点连接与体积检查；未重跑旧合成渲染矩阵。
- 来源明确的本地 FABDEM 地形完成白底、透明、1 倍尺度验收，独立 venv 安装 wheel 后实际渲染成功。
- 不规则真实高程阈值掩膜在原像元精度下保留 37 个组件、2 个贯穿孔洞；两份场景非流形边和顶点为零，各 825432 次逐格射线检查通过。
- 已目视检查 PNG，保存后重新打开 BLEND 核验，并验证 wheel 包含新的 terrain_mesh.py。
- 详见 acceptance-20261107.md 和 masked-terrain-20261107.md 的数据来源、许可、原件哈希及复现命令。

## 限制

轮廓来自栅格有效区，以网格单元中心最近邻采样；默认最长边 256，最高 1024，细连接、小孔和小岛可能随降采样改变。没有矢量边界的亚像元约束三角化。真实验收使用地形阈值研究区，未冒称行政省界。真北/网格北偏差及垂直基准仍按首次验收记录的范围处理。

真实数据、派生图片及安装产物在被忽略的 outputs 目录，仅源码/测试/说明进入 Git。FABDEM 派生成果继续遵循 CC BY-NC-SA 4.0，与源码 GPL 许可分开。
