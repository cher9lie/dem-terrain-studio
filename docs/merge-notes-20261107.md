# 合并说明草稿

建议标题：Validate real geographic DEM rendering and build closed terrain blocks

真实地理 TIFF 可能包含高程、坡度和坡向等多个波段，原先把 RGB 混为灰度会产生错误地形；矩形地形也只有起伏表面。本次增加显式波段/米制投影/有效区/尺度记录的源码工具，拒绝不一致 RGB 高程，并为无缺测矩形地形添加封闭侧壁和平底。保存的 BLEND 打包纹理，Windows 与已安装 CLI 输出 UTF-8，同时修正 SPDX 元数据需要的构建依赖下限。

验证使用来源明确的本地 FABDEM v1.2 郑州西南山地裁片：白底、透明、1 倍尺度三份 1200×1200 图已渲染并目视检查；保存场景比例、太阳方向、封闭性和纹理打包通过。独立 venv 安装 wheel 后实际完成同一数据渲染。没有重复先前合成数据矩阵。详细数据许可、原件哈希、尺寸与复现命令见 acceptance-20261107.md。

## 范围与限制

预处理依赖为可选 geo extra，基础渲染 wheel 无新增强制依赖。工具随源码提供。输入/输出真实数据和图像仅在本地被忽略的 outputs 目录，不混入 GPL 源码提交；FABDEM 派生成果按 CC BY-NC-SA 4.0 留存。NoData 内部孔洞、多岛及省界封闭实体尚未覆盖。1 倍是相对地理起伏比例，不包括绝对海拔及物理底座高度。Blender 6 的 use_nodes 弃用提示属于后续兼容工作，本次核验版本为 5.1.2。
